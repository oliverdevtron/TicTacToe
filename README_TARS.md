## 🎮 Neue Features der TARS Edition

### Steuerung per Tastatur

| Taste | Funktion |
|-------|----------|
| **[H]** | Humor-Level durchschalten (0% → 50% → 75% → 90% → 100%) |
| **[C]** | C64 Brotkasten-Modus (Retro-Farbpalette) ein/aus |
| **[D]** | Douglas Adams "DON'T PANIC" Easter Egg |
| **[G]** | Conway's Game of Life Animation starten (nach Spielende) |
| **Konami** | ↑↑↓↓←→←→BA für WOPR-Übernahme (jetzt mit TARS-Kommentar) |

### Was der Humor-Level verändert
- **0%** - Nur Joshua/WarGames-Zitate (Original-Modus)
- **50%** - Joshua + TARS (Interstellar) gemischt
- **75%** - TARS-Standard: trocken, clever, witzig (TARS-Empfehlung)
- **90%** - + Douglas Adams ("42", "Don't Panic")
- **100%** - Volle Eskalation. Alle Zitate, alle Easter Eggs.

## Technische Details

- **Sprache:** Python 3 (stdlib + tkinter)
- **Game of Life:** Toroidales Gitter, 12×12 Zellen, 150ms Ticks
- **C64-Palette:** Klassisches Blau (#0000AA)
- **Kompatibel:** Original-Spiellogik unverändert

## Start

```bash
python3 tic_tac_toe_tars.py
```
